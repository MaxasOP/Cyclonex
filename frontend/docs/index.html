Cyclonex methodology and data sources

Risk grids and cell inspection

The dashboard estimates local winds and structural loading from a storm scenario. The 200 m detail view covers a bounded area, while wider runs use coarser cells. The map displays the resolution for each run. Cell inspection shows the calculation behind each screening index.

Weather, ocean and building data

Open-Meteo supplies weather conditions. HYCOM supplies ocean profiles when available. Cyclonex labels climatology estimates when a live profile is unavailable. Building footprints come from bundled reference data or OpenStreetMap queries, with coverage and height assumptions that vary by location.

Forecasts and image analysis

The baseline forecast uses a small reference storm dataset. The experimental satellite models use synthetic training scenes, and their output requires validation on observed storms. The AI Lab identifies the input source and whether a model or heuristic generated the output.

Evacuation routing and reports

Road routes depend on provider availability. Confirm road closures, flood conditions and shelter occupancy with local authorities before relying on a route. Printable reports and CAP exports are scenario exercises.
