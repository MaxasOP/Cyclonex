🛡️ Working Prototype
Production ready with live PyTorch & zero mockups.
1. Frontend: React 19 + TypeScript (strict) + Vite; Three.js for 3D digital twin building extrusions; MapLibre GL for 2D tactical risk grid; Web Speech API for voice TTS warnings. No bulky UI dependencies.
2. Backend: Python + FastAPI serving the science & AI layer: 4 PyTorch models, shallow-water wind stress surge modeling ($S_{wind}=0.00155\cdot V^2$), 6-stage causal rainfall runoff, and IS-875 asset vulnerability.
3. Data & Earth Observation: Google Earth Engine (Copernicus Sentinel-1 SAR floodwater, SRTM 30m DEM, Dynamic World 10m LULC, VIIRS nightlights) + Open-Meteo live meteorology + IBTrACS track archives.
4. Decision Intelligence: Gemini 3.7 Flash multimodal reasoning translating physics telemetry into Evidence ➔ Reasoning ➔ Action directives with deterministic NDMA RuleEngine v2.4 fallback.
5. Deployment: Runs entirely browser-native over WebGL2/WebGPU. No GPU cluster required on client; deployable on standard NDMA/SDMA workstation hardware and mobile browsers.
